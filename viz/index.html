Reading these drawings honestly

  • Nothing here is a fact the database stated. The relationships table is empty; every edge is derived, and edge_kinds in the export records how each one was built.
  • An inf record was concluded by a model, not read off the page; dis is disputed. They are drawn lighter and dashed, never like an explicit claim.
  • Events carry a day range, not a date. Where a span is drawn it is day_lo–day_hi; a point would invent precision the extractor never claimed.
  • An informed edge is one hop, not an answer. It says a message was sent, and where a declared channel gives it a speed, when it arrived. Whether someone could know a thing by a date is derived from those hops plus fork inheritance and channel windows — bp viz answers that against the database.
  • No scene prose and no citation quotes are in this page, by design — so a claim can be traced to a scene id here, but the check of whether the quote supports it has to happen against the database.
